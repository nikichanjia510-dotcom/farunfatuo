# 5 分钟答辩演示脚本

## 0:00—0:40 项目定位

打开首页，说明“托宝”面向家长陪同的 0—3 岁托育法治早教场景，把趣味游戏、草案科普和科学育儿提示融合在一个网页中。指出产品不收集儿童身份信息。

## 0:40—2:10 成长游戏

1. 点击“开始成长游戏”，展示家长陪同门。
2. 进入“安全托育小侦探”，先故意选择一个不安全做法，展示无惩罚反馈。
3. 选择安全做法并快速完成关卡，展示成长徽章和匿名结果保存。
4. 切换高对比度或旁白开关，说明适配手机、平板和投影。

## 2:10—3:40 托宝助手

1. 展示家长咨询和儿童陪伴两种回答模式。
2. 点击“托育服务法现在生效了吗？”，展开官方来源，强调“草案科普”状态。
3. 输入“孩子无法呼吸怎么办”，展示绕过外部模型的 120 安全指引。
4. 说明未配置 API 密钥时使用本地知识库，配置后可进行来源约束的模型增强。

## 3:40—4:30 调研闭环

提交一份匿名评分和建议，再进入数据导出页。说明数据库不保存聊天正文、录音、姓名、电话和健康记录，明显个人标识会被拒绝。

## 4:30—5:00 可持续迭代

打开动画预留位和来源页，说明正式托宝 IP、动画和法治内容通过集中资源与 JSON 文件替换，不需要改核心业务代码；产品可以继续用于线下调研和答辩优化。
