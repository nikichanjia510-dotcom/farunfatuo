# 系统架构

## 组件

```text
浏览器 React SPA
  ├─ 成长游戏 / 语音旁白
  ├─ 双模式助手 / 文字与语音输入
  ├─ 匿名反馈 / 来源说明
  └─ 管理令牌导出
          │ HTTPS / JSON
          ▼
Fastify API（Node.js 24）
  ├─ Zod 输入校验与隐私字段拦截
  ├─ 审核内容加载器（只发布 approved）
  ├─ 安全分类 → 本地关键词检索 → 可选模型增强
  └─ SQLite 匿名数据与 CSV 导出
          │（可选）
          ▼
OpenAI 兼容模型服务
```

生产构建由 Fastify 在同一端口托管 React 静态文件，避免跨域配置。Docker 容器只需要一个持久化数据卷。

## 助手决策顺序

1. 校验长度并拒绝明显手机号、邮箱和身份证号。
2. 命中严重受伤、无法呼吸、虐待、走失等关键词时直接返回 110/120 安全指引，不调用外部模型。
3. 从对应受众可见的 `approved` 知识中按标题和关键词检索前三条。
4. 未配置外部模型时直接返回审核答案。
5. 已配置模型时，只把用户问题和检索内容发送给模型，并要求不得虚构条款、不得把草案说成现行法律。
6. 模型失败、超时或空响应时自动回退审核答案。

助手事件只记录匿名会话、受众、响应模式、知识分类、耗时和安全标记，不记录问题或答案正文。

## 数据表

- `game_results`：匿名会话、关卡、尝试次数、完成状态、耗时、时间。
- `feedback`：匿名会话、角色、评分、标签、建议、时间。
- `assistant_events`：匿名会话、受众、回答模式、分类、耗时、安全标记、时间。

SQLite 开启 WAL。展示版不提供账号、儿童档案或完整运营后台。
