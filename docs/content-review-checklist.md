# 内容审核清单

每次更新游戏或知识库时，由法治内容组和产品技术组共同确认：

## 法律准确性

- [ ] 使用的是官方原文或政府公开来源，链接可访问。
- [ ] 草案统一写成“草案提出”“草案拟规定”，没有写成已生效法律。
- [ ] 条款章节、来源状态和 `updatedAt` 已更新。
- [ ] 地方办理流程标注“以属地现行公开信息为准”。
- [ ] 不承诺案件结果，不替代律师、公安、医疗和主管部门。

## 儿童安全与表达

- [ ] 语言不责怪、不恐吓儿童，不制造失败和羞耻感。
- [ ] 身体边界内容强调可信照护、表达不适和及时告诉大人。
- [ ] 紧急场景明确 110 / 120，并禁止等待网络答复。
- [ ] 活动适合家长陪同，不宣称 0—3 岁儿童可独立操作。

## 隐私与素材

- [ ] 示例不包含真实姓名、电话、身份证号、健康记录或可识别照片。
- [ ] 正式 IP、徽标、动画、字体和音乐已取得使用授权。
- [ ] 所有图片有合适的替代文本，动画有字幕。

审核通过后才把 `reviewStatus` 改为 `approved`，并执行 `pnpm check`。
