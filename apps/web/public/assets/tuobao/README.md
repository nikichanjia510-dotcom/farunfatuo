# 托宝素材替换说明

当前 SVG 仅为中性占位形象，不是最终“托宝”IP。正式素材到位后：

1. 将透明背景主形象导出为 `mascot-main.webp`，建议 1200×1200。
2. 将动画封面导出为 `legal-video-poster.webp`，建议 1920×1080。
3. 将动画导出为 `legal-video.mp4`，并提供 `legal-video.zh-CN.vtt` 字幕。
4. 按 `asset-manifest.json` 更新文件名和替代文本，再修改对应组件引用。

不要把院徽、团徽或儿童照片直接合入产品，除非项目负责人已确认使用授权与隐私同意。
